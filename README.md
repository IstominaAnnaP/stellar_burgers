# 🚀 Автоматизированное тестирование Stellar Burgers

Проект с автотестами для веб-приложения космической бургерной **Stellar Burgers** (дипломный проект курса в Яндекс Практикуме).

## 📋 Что протестировано
* **Unit-тесты:** модульное тестирование позитивных сценариев логики модуля `burger.py` с применением параметризации и моков.
* **API-тесты:** проверка эндпоинтов регистрации, авторизации, создания заказов.
* **UI-тесты (Page Object):** проверка основного функционала в браузере (конструктор бургеров, лента заказов, личный кабинет, модальные окна).

## 🛠 Стек технологий
* **Python**
* **Pytest** — запуск тестов и фикстуры
* **Selenium WebDriver** — автоматизация браузера
* **Requests** — тестирование REST API
* **Allure** — формирование отчетов о прохождении тестов

Проект объединяет всю пирамиду тестирования (**Unit**, **API** и **UI**) в единую модульную архитектуру с общим ядром, гибридной подготовкой тестовых данных и сводной отчётностью в **Allure**.

## 🧭 Навигация по проекту и тестовому покрытию

### 1. Уровни тестирования (Что проверяется)

| Уровень | Директория | Описание и ключевые проверки |
| :--- | :--- | :--- |
| **Unit-тесты** | [`tests/unit/`](tests/unit/) | Модульное тестирование бизнес-логики ([`burger.py`](app/burger.py)): проверка выбора булок и ингредиентов, расчёта итоговой стоимости бургера, формирования чека и изоляции зависимостей с помощью моков (`unittest.mock`). |
| **API-тесты** | [`tests/api/`](tests/api/) | Тесты REST API: регистрация и авторизация пользователя, создание заказов. |
| **UI-тесты (E2E)** | [`tests/ui/`](tests/ui/) | Кроссбраузерные пользовательские сценарии в **Chrome** и **Firefox**:<br>• **Конструктор:** просмотр деталей ингредиентов, перетаскивание (`drag-and-drop`) в корзину, динамика счётчиков, оформление заказа.<br>• **Лента заказов:** отображение заказов в работе и выполненных, рост счётчиков «За всё время» и «За сегодня». |

### 2. Архитектура

* **Ядро взаимодействия с системой ([`core/`](core/)):**
  * [`core/api/`](core/api/) — API-клиенты (`UserMethods`, `OrderMethods`), инкапсулирующие работу с HTTP-запросами и эндпоинтами.
  * [`core/ui/pages/`](core/ui/pages/) — паттерн **Page Object Model (POM)**.
  * [`core/ui/locators/`](core/ui/locators/) — изоляция селекторов от логики страниц (устойчивые XPath-локаторы с осями и без привязки к динамическим хэшам сборки).
* **Управление данными и конфигурацией ([`core/utils/`](core/utils/)):**
  * [`urls.py`](core/utils/urls.py) — единый реестр базового URL, UI-маршрутов и API-эндпоинтов.
  * [`generators.py`](core/utils/generators.py) — генерация уникальных тестовых пользователей.
* **Оркестрация прогона ([`conftest.py`](conftest.py) & [`pytest.ini`](pytest.ini)):**
  * Параметризованные фикстуры инициализации WebDriver (Chrome / Firefox).
  * Автоматическая подготовка и очистка тестового пользователя через API-слой для полной автономности UI-тестов.

## ✨ Инженерные решения в проекте

* **Гибридный подход (API + UI):** Для независимости от периодического сброса тестовой БД и ускорения прогонов тестовый пользователь автоматически создаётся перед сессией через API-слой (`core/api/user_methods.py`) и удаляется после завершения тестов.
* **Защита от флаки-тестов (Flaky tests):** Применены относительные XPath-локаторы с опорой на текстовые метки и оси (`following-sibling`, `preceding-sibling`), исключающие падения при пересборке фронтенда. Реализовано явное ожидание скрытия фоновых оверлеев (`Modal_modal_overlay`) для стабильной работы в Firefox и Chrome.
* **Единая отчётность Allure:** Все уровни тестов (Unit, API, UI) размечены шагами (`@allure.step`) и собираются в общий отчёт.

### 🚀 Как запустить локально

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/IstominaAnnaP/Yandex-Scooters.git
   ```
   ```bash
   cd Yandex-Scooters
   ```
2. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Запустите тесты с сохранением результатов для Allure:**
   ```bash
   pytest --alluredir=allure_results
   ```

4. **Сформируйте и откройте отчет Allure:**
   ```bash
   allure serve allure-results
